# Beurt Balie — releases

Installers and auto-update manifests for **Beurt Balie**, the UwBeurt
desk companion (Windows system-tray app for desk staff). The source
code lives in a private repository; this repo only carries built
artifacts.

- **Install**: download the latest `BeurtBalie-Setup-<version>.exe`
  from [Releases](../../releases/latest) and run it (one-click,
  per-user, no admin rights).
- **Updates**: installed apps check this repo automatically and update
  themselves overnight.
